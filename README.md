# Наставник — ИИ-коуч со «звонками», которые нельзя просто сбросить

APK: `dist/Nastavnik.apk` (Android 8.0+, подписан `release.keystore`, alias `nastavnik`).
Сборка: `JAVA_HOME=... ANDROID_HOME=~/android-sdk ./gradlew testReleaseUnitTest assembleRelease`.

> **Не психологическая и не медицинская помощь.** Приложение не заменяет консультацию специалиста. Если вам тяжело или есть угроза жизни — звоните **112** или **8-800-2000-122**.
>
> [Политика конфиденциальности](https://ivanivorontsov-sudo.github.io/supersmart-privacy/nastavnik.html) · [Сторонние компоненты](THIRD_PARTY_NOTICES.md)

## Методики
GROW (8-шаговая коуч-сессия при постановке цели), SMART (метрика и срок), WOOP / ментальное контрастирование (желание → результат → препятствие → план),
намерения «если — то», habit stacking (привязка к существующей привычке), правило малых шагов, серии (streaks), ежедневная вечерняя рефлексия,
проактивные чекины коуча, подотчётность через фото-доказательства.

## Сценарий звонка (машина состояний `core/CallFlow.kt`, 11 unit-тестов)
1. Звонок: «Отложить» на 10 или 15 мин (максимум 2 раза) или «Принять». Сбросить нельзя (кнопка «Назад» отключена, «Отклонить» в уведомлении открывает экран выбора). Нет ответа 90 с → пропущенный, перезвон через 5 мин.
2. Принять → таймер на время задачи. Продлить можно 1 раз (+то же время). Не успел за 2× время → снова звонок, цикл заново.
3. «Выполнено» → только живая камера CameraX (никакой галереи/выбора файла) → фото в фоне уходит в vision-ИИ с НЕИЗМЕНЯЕМЫМ зашитым промптом (`ai/Prompts.kt`) → строгий JSON `{done, confidence, reason}` (терпимый разбор + валидация схемы, `ai/Json.kt`). Закрывается только при `done && confidence ≥ порога` (по умолчанию 75%). Иначе таймер продолжается или (если время вышло) звонок повторяется.
4. Успех → случайная похвала из 30 вариантов.
5. Ругань (текст на экране звонка/таймера) при: пропусках, пока телефон был выключен; 2 откладываниях; продлении/просрочке таймера. При выбранном Grok и включённом «жёстком режиме 18+» — кнопка «Прослушать Грока»: речь с матом генерируется в фоне ТОЛЬКО по нажатию и озвучивается TextToSpeech (ru). Без слюров, угроз и самоповреждений (закреплено в промпте). По умолчанию выключено, включение — с предупреждением 18+.

## Никогда не включает выключенный телефон
Используется только `AlarmManager.setExactAndAllowWhileIdle(RTC_WAKEUP)` — будит из сна, но не из выключенного состояния. `setAlarmClock` и любые power-off-alarm API не используются (на realme/ColorOS и др. они могут включать телефон).
После `BOOT_COMPLETED` всё перепланируется; звонки, пропущенные пока телефон был выключен, НЕ звонят задним числом — они попадают в «Пропущенные» и одно сводное уведомление.

## Фон
Все запросы к ИИ (план, чат, рефлексия, проверка фото, чекины, речь Грока) — в WorkManager: expedited, ограничение «есть сеть» (офлайн-очередь), экспоненциальные повторы, foreground-уведомление типа dataSync. Результаты пишутся в Room и приходят уведомлениями; работает при закрытом приложении и заблокированном экране. Ежедневный проактивный чекин коуча — периодическая задача.

## ИИ
GigaChat (OAuth по ключу авторизации, сертификаты НУЦ Минцифры встроены, vision через загрузку файла), DeepSeek (без vision), Qwen (DashScope, qwen-vl), Gemini, Grok (xAI, `https://api.x.ai/v1`), любой OpenAI-совместимый. Демо-режим без ключей (проверка фото по яркости/детальности кадра — тёмный/пустой кадр отклоняется).
**Без ключа через веб-чат** (Grok, DeepSeek, GigaChat, Qwen): вход один раз в Настройках (cookies сохраняются), запросы идут через скрытый WebView с адаптированным `capture.js` из «ПрокурорПлюс».
Ограничения веб-режима: зависит от вёрстки сайтов (может сломаться при их обновлении), капча/разлогин требуют повторного входа, фоновые WebView на агрессивных прошивках могут убиваться, фото в веб-чат вкладывается скрытно (input[type=file] через DataTransfer, запасной путь — вставка из буфера); если сайт поменял загрузку, фото не прикрепится и проверка вернёт ошибку — тогда нужен API-ключ vision-модели.
